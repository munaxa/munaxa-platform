## 4. Startup dependencies, health, failure behaviour

Identity: Valkey sidecar HEALTHY first (services.tf:151-167); RDS reachable over TLS; secrets resolved by the agent (a missing JSON key or a version pin mismatch stops the task before start). Container health: `/api/auth/health/live`; ALB target health: `/api/auth/health/ready`, which checks DB, cache and required tables and returns 503 otherwise (identity health.controller.ts:41-53). With the database stopped or migrations not run: targets unhealthy, ALB answers 503; circuit breaker marks the deployment failed (first deployment has nothing to roll back to). Valkey restart resets lockout counters (accepted in ADR §1 for one task).
