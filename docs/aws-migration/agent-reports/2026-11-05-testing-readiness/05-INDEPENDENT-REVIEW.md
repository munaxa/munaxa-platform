- **Secret bundles:** the key lists in `01` and `03` §5 match `data.tf` `local.secret_keys` and `docs.tf` `docs_app_keys` (11 keys), `docs_operator_keys` and `docs_provision_keys`. - **Licensing:** production refuses permissive licensing in Work (`licensing.ts` 53 to 60), School (`env.validation.ts`, `DATABASE`) and Docs (`configuration.ts`, `NONE`). The stack sets `LICENSING_MODE=CONTROL_PLANE` for all three.

Terraform refuses a Control image without `operator_access`. The publisher role path and trust (`/munaxa-shared/bootstrap/`, `environment:image-release`, `refs/tags/image/*`) match `03` §4.
- **Session crons:** `aws-session.yml` uses `17 19 * * *` and `47 1 * * *`, and the backstop schedule is UTC (`backstop.tf`). See R-3 for how the runs actually behaved.
