# 07. IAM and threat model (L-A0 redesign, PR #131)

## 1. Who can read the operator password

The value of `munaxa-nonprod/identity-operator` can be read only where **both** an identity policy
allows it **and** the secret's resource policy does not deny it.

| Principal | Identity policy | Resource policy | Net |
| --- | --- | --- | --- |
| identity-bootstrap execution role (`role/munaxa-shared/munaxa-nonprod-identity-bootstrap-execution`) | `ops.tf` Sid `ReadOwnerUrlAndOperatorSecret`: `GetSecretValue` on exactly `…:secret:munaxa-nonprod/identity-migrate-??????` and `…:secret:munaxa-nonprod/identity-operator-??????` | denied unless `BootstrapReadWindow = open` (statement 1) and before `WindowExpiresAt` (statement 3) | only during an open, unexpired window; used by ECS to inject the two keys into the bootstrap container |
| root (the owner and the AWS connector) | full | statement 2 denies `GetSecretValue` unless `aws:CalledVia` contains `cloudformation.amazonaws.com` (`ForAllValues:StringNotEquals`, which is also true when the key is absent, so a direct call is denied) | only CloudFormation acting for root (for example while generating a new version). No direct read from the connector or the console |
| nonprod deployer role (GitHub Actions) | no `GetSecretValue` on this name | statement 1 denies everyone except root and the role | no direct read |
| session-cleanup role | explicit deny on every secret except the retired one-run copy | statement 1 | none |
| any other principal, other accounts | none | statement 1, `BlockPublicPolicy` | none |

Writes (`PutSecretValue`, `UpdateSecret`, `UpdateSecretVersionStage`, `RotateSecret`,
`CancelRotateSecret`, `DeleteSecret`, `RestoreSecret`, `PutResourcePolicy`, `DeleteResourcePolicy`,
`TagResource`, `UntagResource`, `ReplicateSecretToRegions`, `RemoveRegionsFromReplication`,
`StopReplicationToReplica`) are denied to every principal except root (statement 4). Root changes
the secret only through the stack (C-8G) by procedure; a direct change is detectable by C-24.

## 2. Threat model

| # | Threat | Control | Residual |
| --- | --- | --- | --- |
| T1 | The password reaches the AWS connector's records (the original L-A0) | Generated by Secrets Manager inside CloudFormation; C-8G calls no value API; the harness refuses all value and write APIs; root cannot read directly | None found. Verified by tests that scan every fake request and result for the value |
| T2 | The email leaks to a public place | `NoEcho` parameter, placeholder in the repository; sent only by `create`; the `create` call record is never committed | L3 (below): the email is in the bootstrap CloudWatch logs and in CloudTrail's view of `CreateStack` (NoEcho masking not verified) |
| T3 | The password in Terraform state or a plan | Terraform never manages the value; the task definition holds `valueFrom` only | None |
| T4 | A second copy of the secret | One secret; `create` refuses if the legacy copy exists; C-24 flags its creation; C-16 deleted | None |
| T5 | A forgotten open window | `WindowExpiresAt` (5 to 120 min) is enforced by the policy itself; `close-window` on every exit path; H-20 and the runbook require it | Up to the window length |
| T6 | The nonprod deployer exfiltrates during an open window by registering a task definition that uses the bootstrap execution role and running it (`RegisterTaskDefinition`, `iam:PassRole`, `ecs:RunTask`) | Window bounded in time and only opened by the operator just before the bootstrap; the deployer can already read every other nonprod secret; C-24 lists every value read | **Accepted (review B-H1).** A `PassRole` deny is not possible because Terraform passes that role. Follow-up: C-24 correlation of reads against `RunTask` events |
| T7 | Accidental deletion | `DeletionPolicy`/`UpdateReplacePolicy` Retain; stack termination protection; the harness refuses `DeleteSecret` | None |
| T8 | A broken generated JSON | The email pattern refuses quotes, backslashes and spaces; the generator excludes quotes, backtick and backslash | None |
| T9 | A weak generated password | 40 characters, every character type; the bootstrap validates the platform policy before it writes | Negligible chance of a trivial-pattern refusal; recovery is `regenerate` |
| T10 | An AWS error message carrying a value into a result | `code_of` returns codes only; `ResourceStatusReason` is never read | None |
| T11 | The template or policy drifts from the reviewed one | `status` compares `GetTemplate` with the embedded template and checks the live policy statement by statement | None |
| T12 | Production impact | Names, KMS alias and role are nonprod only; the template has no `prod` string (test) | None |
