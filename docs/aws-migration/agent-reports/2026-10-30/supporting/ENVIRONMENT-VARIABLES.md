# Environment variables: names only

30 Oct 2026, Agent 7, consolidated from the Agent 2 to 6 reports and checked against platform
`services.tf` and `data.tf`. No values. **S** = secret (Secrets Manager bundle `munaxa-nonprod/<bundle>`),
**P** = plain task env set by Terraform, **B** = build-time.

IDENTITY_SIGNING_KID, IDENTITY_DEFAULT_ORGANISATION, CSRF_TRUSTED_ORIGINS, LOG_PRETTY,
