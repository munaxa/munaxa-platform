# @munaxa/theme

Munaxa theme engine — the typed product-theme registry (Corporate, School, Work, Docs) and the CSS theme contract. Branding is configuration, never duplicated code.

This package is a **façade**. It contains no implementation — every export is
re-exported from [`@munaxa/platform`](../platform), which is the single source of
truth for the Munaxa design system. The façade exists so products depend on a stable,
intention-revealing package name while the platform's internal layout stays free to
change.

## Install

```bash
pnpm add @munaxa/theme
```

## Entry points

- `@munaxa/theme`
- `@munaxa/theme/css/base`
- `@munaxa/theme/css/corporate`
- `@munaxa/theme/css/school`
- `@munaxa/theme/css/work`
- `@munaxa/theme/css/docs`

## Changing something

Edit `packages/platform`, not this directory. Files here are generated by
`scripts/gen-facades.mjs` and are overwritten on regeneration.
